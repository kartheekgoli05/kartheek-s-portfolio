A real-time sales command center that started as a layer over Google Sheets and grew into a full editable replacement for it. Everything is editable inside the dashboard — add rows (leads, tools, freelancers) and add columns (custom fields and metrics) without touching a spreadsheet.
Hybrid data model: existing Sheets data is imported, while Supabase (PostgreSQL) stores everything created or edited in-app — on conflict, the dashboard wins. Custom columns are added on the fly via a flexible key-value store, so new fields ship with no schema changes.

Tools ROI auto-attributes leads to the channel that generated them and computes cost-per-lead, full-funnel conversion, and ROI per tool.

AI Content Intelligence Platform
An AI content engine that learns each client's voice and gets measurably better with every piece the team approves — so output reads on-brand from day one, not after months of manual editing.
Built around a Client Brain — a structured profile (tone, vocabulary, goals, forbidden phrases) injected as a cached system prompt into Claude on every generation. The key layer is a learning loop: when the team rates and approves a piece, Claude extracts concrete lessons from the feedback and folds them back into the brain. The system literally gets smarter with use.
Covers every format (LinkedIn, press releases, whitepapers, newsletters) with structure templates per format, live web research with citations built into generation, a full Blog Studio with SEO scoring and multi-format academic citations, and an approval workflow that doubles as the training signal. Cost-aware routing runs Claude Sonnet for publication-quality writing and Claude Haiku for high-volume background tasks — cutting ~70% of token cost via cached prompts.
